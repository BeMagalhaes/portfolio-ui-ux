# Portfólio — Benedita Magalhães

Portfólio UX/UI Designer · foco em **IA · UI · Design Systems**. Página única, bilíngue (PT/EN), tema escuro.

## Deploy rápido (GitHub Pages)

O arquivo **`index.html`** é autossuficiente — funciona offline, sem dependências externas. Basta:

1. Criar um repositório no GitHub e enviar este projeto.
2. Em **Settings → Pages**, apontar para a branch `main` / pasta raiz.
3. O site fica disponível em `https://<seu-usuario>.github.io/<repo>/`.

## Estrutura

- `index.html` — build final autossuficiente (imagens, fontes e estilos embutidos). **É o que vai ao ar.**
- `Portfólio Benedita Magalhães.dc.html` — arquivo-fonte editável do portfólio.
- `assets/` · `uploads/` — imagens usadas no arquivo-fonte.

Para editar, altere o `.dc.html` e gere um novo `index.html`.
